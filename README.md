# Dream Worlds

An immersive ambient mixer prototype that opens directly into a full-screen video world. It uses its own playback controls, keeps the mixer hidden until requested, and pairs scene sources with recorded ambience layers. The default and lakeside scenes use local 1080p Coverr footage; the pond scene remains the original supplied loop.

## Run locally

Serve this folder over HTTP, then open `index.html`. For example, a simple local static server on port 4173 is sufficient.

## Included sound sources

- “Rain (1)” by ezwa, public domain, via Wikimedia Commons.
- “forest ambience” by nille, public domain, via Wikimedia Commons.
- “Cafe ambiance” by Marble Toast, CC0, via Wikimedia Commons.
- “Brownnoise”, public domain, via Wikimedia Commons.

The default online scene uses the Ghibli piano YouTube source supplied in the project brief. The YouTube player is non-interactive and visually cropped; all playback and volume actions use the app’s own controls.
